# Bundled third-party license texts

The Windows package places this directory next to `DeepSonder-PySide6.exe` so the
license terms for redistributed runtimes and fonts remain directly available
after extraction.

| Component | Current build / asset version | License text |
| --- | --- | --- |
| Qt for Python / PySide6 / Shiboken | 6.8.3 | `third-party/GNU-LGPL-3.0.txt` and `third-party/GNU-GPL-3.0.txt` |
| CPython runtime | 3.12.x | `third-party/PYTHON-3.12-LICENSE.txt` |
| PyInstaller bootloader | 6.22.2 | `third-party/PYINSTALLER-COPYING.txt` |
| Material Symbols | bundled font files | `third-party/APACHE-2.0.txt` |
| Hanken Grotesk, Inter, JetBrains Mono and Source Serif 4 | bundled font files | `third-party/SIL-OFL-1.1.txt` |

See [THIRD_PARTY_NOTICES.md](../THIRD_PARTY_NOTICES.md) for component notices and upstream links.

`third-party/JAVASCRIPT-MIT-NOTICES.txt` remains an unchanged historical
attribution record for the retired frontend. Its presence does not indicate that
the current PySide6 package includes Electron, React or a JavaScript runtime.
License originals and copyright notices are preserved.
