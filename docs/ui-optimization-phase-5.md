# PySide6 UI 第五轮优化

日期：2026-09-17

## 设置页结构

将单页长表单拆分为写作、AI 与连接、外观、数据四个页签，各页独立滚动。固定保留保存状态、保存按钮、恢复默认和放弃修改入口。减少重复标题占用，改善窄窗口和高缩放下的可见内容。

启动参数、附加参数及固定运行说明默认收起至高级区域；仅选择自定义历史章节或自定义模型窗口时显示相应数值输入行。所有既有配置项和预算计算规则保留。

## 草稿与保存

- 修改设置只改变当前会话内草稿；切换页面或外部切换主题不会清除草稿。
- 保存只合并相对于草稿基线实际修改的选项，保留其他入口刚更新的主题和项目元数据。
- 放弃修改恢复最新已保存配置；恢复默认只载入默认表单值，需点击保存才写入，不重置最近项目等非表单信息。
- 无修改时禁用保存和放弃按钮。保存失败保留草稿及错误说明；写入配置失败时不先更新设置控制器的运行配置。
- 退出时若仍有设置草稿，提供保存、放弃或取消。验证或保存失败会阻止退出，并回到设置页处理。

## 校验与反馈

启动参数和附加参数分别检查引号。错误显示在对应输入项下方，同时切换到 AI 页签、展开高级区、移动输入焦点并滚动到错误位置；提供字段无障碍描述。输入修正后清除该字段提示。校验失败不会发出保存或连接测试请求。

原有连接测试和 AI 引擎行为保留。本轮没有调用真实 AI 服务，也没有更改 AI 结果审阅、正文写入或项目数据格式。

## 验证

新增设置页与主窗口测试覆盖草稿、恢复默认、参数校验、条件行、页面切换、外部主题更新、项目元数据保留、磁盘写入失败和退出选择。界面在 1100×720、浅色、深色及 150% 缩放下使用独立预览脚本验证，截图保存在忽略目录 `build/ui-review-phase-5/`。

设置草稿限当前会话，不提供崩溃后的草稿恢复。修改保存在 PySide6 自身配置中；本轮没有修改 Electron 或演示小说。

- 最新默认值合并边界的设置专项回归 9 项通过。
- 编译检查、运行资源自检及 `git diff --check` 通过。
