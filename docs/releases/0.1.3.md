# DeepSonder 0.1.3（PySide6）

发行标识为 **DeepSonder-PySide6**，标签为 `pyside6-v0.1.3`。本版集中改善章节写作、正文排版、阅读位置恢复与结果审阅体验。

## 本版更新

- 章节编辑改为标题、写前准备与正文组成的写作页，正文置于内嵌圆角书写面，减少界面干扰；常用参考、专注和创作入口保持可达。
- 正文支持推荐、自定义和铺满三种行宽，可拖动两侧把手或使用菜单与键盘调整；窄窗口保留偏好，窗口变宽后恢复。
- 写作设置集中提供正文字号、行距、可收起的效果预览与恢复推荐排版。新配置推荐 18px、1.8 倍行距，已有配置保留原排版偏好；调整只影响显示。
- 切换章节和重启后恢复正文光标、选区与阅读位置；字号、行距和行宽连续变化时尽量保持阅读内容，优化长单段落的重复布局开销。
- 常用导航收敛为写作、资料和检查，项目管理与更多操作分组呈现；任务状态紧凑显示，上下文和工作记录按需展开。
- AI 结果在宽窗口中并排审阅，窄窗口使用完整审阅页；支持查看候选与差异、稍后继续审阅，采用仍需明确确认，来源变化后阻止写入。
- 正文、资料与故事规划统一保存反馈；写入失败和外部版本冲突持续提示，并提供重试、草稿副本与恢复入口。
- 打包程序增加使用临时项目的整窗自检，覆盖配置、阅读位置、待审结果和外部修改冲突保护。

## 下载与安装

下载本 Release 的 `DeepSonder-PySide6-v0.1.3-windows-x64.zip`、`SHA256SUMS.txt` 和 `release-manifest.json`。ZIP 为 Windows x64 便携包，完整解压后运行 `DeepSonder-PySide6.exe`，基础写作无需安装 Python。

更换程序前请退出旧版并备份完整写作项目，将新包解压到独立的可写目录。请核对 ZIP 的 SHA-256 与同版 `SHA256SUMS.txt` 一致；`release-manifest.json` 记录版本、源码提交与构建环境。

AI 功能需要自行安装并配置 DeepSeek Harness，连接步骤见[使用指南](https://github.com/xiauho/DeepSonder/blob/main/docs/user-guide.md)。

## 数据与兼容边界

PySide6 系列独立维护，不提供自动更新或旧 Novalist 就地升级。旧项目只读导入时创建新项目，仅复制名称、作者和有序章节 Markdown，不修改源项目。配置、缓存和个人项目不纳入发布包。

生成内容仍须人工审阅并明确确认采用，保留取消、过期上下文检查、文件修订锁和原子写入保护。程序未做 Authenticode 签名。

## 已知限制

真实 Windows 输入法候选窗尚未完成人工验收；组合、提交、取消与排版变化已有合成输入事件测试，不能替代系统候选窗验证。超长文本仍有全文解析和同步成本，实际速度取决于项目与运行环境。
