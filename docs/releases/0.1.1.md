# DeepSonder 0.1.1（PySide6）

发行标识为 **DeepSonder-PySide6**，标签为 `pyside6-v0.1.1`，提供 Windows x64 便携包。本版重点优化记忆更新的等待、失败恢复及编辑后复用。

## 本版更新

- 调用前统一检查正文分块、归并批次、必要设定与状态的输入预算；不截断正文及证据，归并不收敛时停止重复请求。
- 整次记忆生成等待上限默认 30 分钟，可在“设置 → AI 与连接”调整；取消或超时后保留此前已校验的缓存，迟到结果不进入缓存或审阅。
- 归并逐批保存检查点，中断后复用已完成批次；紧凑事实传输保留完整字段、文本和锚点，返回引用必须匹配当前请求。
- 记忆任务默认一次请求，可选同时两次的试验模式。两路独立客户端隔离任务文件，结果按来源顺序合并；明确限流后只对未完成部分回退串行。
- 长章节分块可在局部编辑后重新同步。仅精确正文及邻段上下文匹配时复用事实，按当前正文重映射证据位置并重新生成本地事实 ID；重复段落及超长段落碎片采用保守失效策略。
- 稳定任务面板计时与快捷导航测试，修复浮点边界偶发失败和测试窗口资源累积。

生成结果仍须人工审阅并明确确认采用；正文、章前状态及相关设定变化后，旧提案不能直接写入。

## 下载与安装

1. 从 [本版本 Release](https://github.com/xiauho/DeepSonder/releases/tag/pyside6-v0.1.1) 下载 `DeepSonder-PySide6-v0.1.1-windows-x64.zip`。GitHub 自动生成的 Source code 是源码。
2. 退出旧版程序，备份整个写作项目，将新包完整解压到新的可写目录。不要覆盖项目目录，不要仅替换单个 EXE。
3. 在 Windows 10/11 x64 上运行 `DeepSonder-PySide6.exe`；基础写作无需安装 Python。当前仅发布 Windows x64 包。

可使用 PowerShell 校验下载文件：

```powershell
Get-FileHash .\DeepSonder-PySide6-v0.1.1-windows-x64.zip -Algorithm SHA256
```

结果应与同一 Release 的 `SHA256SUMS.txt` 一致。`release-manifest.json` 记录版本、源码提交、构建环境、包大小与校验值。

## AI 与缓存

- AI 功能需要自行安装并配置 [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness)，并在“设置 → AI 与连接”测试连接。本包不包含模型、服务凭据或外部引擎。
- 旧事实、归并与提案缓存与新版本隔离，升级后第一次记忆更新可能重新提取；已采用记忆及项目正文不迁移。相同内容再次运行可复用合法缓存。
- 同时两次请求保持试验性质。实际吞吐、延迟和质量取决于引擎、模型服务及章节内容；更换外部模型配置后可使用“重提事实”。
- 合成样本的编辑后缓存命中不能等同于真实模型总耗时改善；稳定边界也可能增加首次提取的块数。实现及验证范围见 [记忆更新说明](https://github.com/xiauho/DeepSonder/blob/pyside6-v0.1.1/docs/memory-performance.md)。

## 保留边界

- 项目格式、配置和发行渠道属于独立 PySide6 系列；不保证 Electron 项目格式兼容，不提供旧 Novalist 就地升级或自动更新。
- 旧项目只读导入仅复制名称、作者和有序章节 Markdown，创建新项目；旧记忆、设定、关系图、缓存及回收站不导入，源项目不修改。
- 本次未完成不同模型服务、全部 Windows 设备及全新实体机器的兼容矩阵。程序未做 Authenticode 签名，Windows 可能提示未知发布者；请核对下载来源与校验值。
- 程序配置位于 `%APPDATA%\DeepSonder\PySide6`，缓存位于 `%LOCALAPPDATA%\DeepSonder\PySide6`；发布包不包含本地项目、个人配置或缓存。
- 主动运行 AI 任务时，所需正文和相关资料可能通过 `dsh` 发往配置的服务。详见 [隐私说明](https://github.com/xiauho/DeepSonder/blob/pyside6-v0.1.1/PRIVACY.md)。
