# DeepSonder 0.1.2（PySide6）

发行标识为 **DeepSonder-PySide6**，标签为 `pyside6-v0.1.2`。本版集中改善资料编辑、页内导航及桌面窗口交互。

## 本版更新

- 主窗口将菜单、拖动区域与窗口控制整合到顶部，专注模式保留退出和窗口控制；修复菜单对齐及最小化恢复后的焦点提示。
- 资料页统一模块、字段、分组及关系的编辑入口，支持自动保存、跨会话模块折叠和宽窄窗口分区导航；失败与外部版本冲突持续提示并保留草稿。
- 同步区以只读信息显示同步状态和截止章节，保留受保护的章节跳转、同步预览与确认流程。
- 资料编辑支持文档级撤销／重做，覆盖输入和结构操作；普通保存及自动保存后仍可撤销。历史仅在当前会话内保留，最多100步及16 MiB快照估算内存。
- Ctrl+F在当前资料草稿内查找模块、字段、正文、关系和备注，提供命中计数、前后循环与临时展开；结构调整后继续按模块身份定位。
- 基础档案按可用宽度、字号和内容自动切换单双列；空白导语收为“添加资料概述”，保留输入焦点、选区与历史。
- 窄侧栏使用着色状态圆点，提供悬停、键盘焦点、辅助说明与Alt+Enter状态入口；圆点和外圈共用几何圆心，适配明暗主题、字体及显示缩放。
- 故事时间轴与故事规划采用统一页面骨架，改进窄窗口及大字号布局。

## 安装与使用

Windows x64便携包名称为 `DeepSonder-PySide6-v0.1.2-windows-x64.zip`。标签工作流完成测试、构建、自检和ZIP审计后生成Actions artifact；公开Release及资产由维护者另行发布。

使用发布包前退出旧版并备份完整写作项目，将压缩包完整解压到新的可写目录，运行 `DeepSonder-PySide6.exe`。基础写作无需安装Python，AI功能仍需自行安装并配置DeepSeek Harness。安装与连接步骤见[使用指南](../user-guide.md)。

下载后的SHA-256应与同一版本的 `SHA256SUMS.txt` 一致，`release-manifest.json`记录源码提交与构建信息。

## 数据与兼容边界

AI生成内容仍须人工审阅并明确确认采用，保留过期上下文检查、取消、文件修订锁和原子写入保护。本版不提供自动更新或旧Novalist就地升级；旧项目只读导入创建新项目，仅复制名称、作者和有序章节Markdown，不修改源项目。

PySide6版本、配置和发布渠道独立维护。配置、缓存和个人项目不纳入发布包。程序未做Authenticode签名；隐私与反馈规则见仓库的 `PRIVACY.md` 和 `SECURITY.md`。
