# DeepSonder 0.1.0-beta（PySide6）

DeepSonder 首个 PySide6 公开测试版，独立于历史 Novalist 与 Electron 系列。发行标识为 **DeepSonder-PySide6**，Git 标签为 `pyside6-v0.1.0-beta`。

## 下载与启动

1. 从 [本版本 Release](https://github.com/xiauho/DeepSonder/releases/tag/pyside6-v0.1.0-beta) 下载 `DeepSonder-PySide6-v0.1.0-beta-windows-x64.zip`；GitHub 自动生成的 Source code 为源码，不是可直接运行的程序。
2. 使用 Windows 10/11 x64，将 ZIP 完整解压到可写目录。不要在压缩包内直接运行，也不要只移动 EXE。
3. 双击 `DeepSonder-PySide6.exe`。基础写作无需另装 Python；AI 功能需自行安装并配置 DeepSeek Harness。
4. 新建项目或打开本系列项目。将写作项目保存在独立目录，定期复制整个项目目录备份。

可用 PowerShell 校验下载文件：

```powershell
Get-FileHash .\DeepSonder-PySide6-v0.1.0-beta-windows-x64.zip -Algorithm SHA256
```

结果应与同一 Release 的 `SHA256SUMS.txt` 一致。`release-manifest.json` 记录版本、源码提交、构建环境、包大小与校验值。

程序未做 Authenticode 签名；Windows 可能提示未知发布者。请先核对下载来源及校验值。当前仅提供 Windows x64 包，未验证 ARM、macOS 或 Linux 安装包。

## 首次配置 AI

- 按 [DeepSeek Harness 官方项目](https://github.com/deepseek-ai/deepseek-harness) 的说明安装并配置外部 `dsh`，服务凭据由它管理。
- 在 DeepSonder 的“设置 → AI 与连接”中配置命令、启动参数和超时，并运行连接测试。默认命令为 `dsh`、配置为 `headless`；特殊环境可使用绝对路径。
- AI 运行依赖外部工具与模型服务，可能产生对应服务费用。不同模型的格式遵循、质量和延迟仍需实际确认。本版不包含模型、API 密钥或 DeepSeek Harness。
- 生成结果先审阅后采用。记忆阻断时，可按错误定向重试、重新提取事实，或在可隔离时审阅可用部分。

## 本版能力

- 章节 Markdown 写作、大纲与剧情简写、自动保存、资料导航、快捷命令和深浅主题。
- 角色及世界观资料、故事规划、作者编排的纵向时间轴与章节事件素材。
- AI 续写、扩写、选区处理、文风审校与一致性检查。
- 章节事实提取、带证据的记忆更新、冲突反馈、人工采用和历史上下文。
- 后台任务、取消、延后审阅、过期结果保护及原子数据写入。
- 旧 Novalist 项目的只读导入：仅名称、作者和有序章节 Markdown；新建目标项目，源项目保持不变。

## 已知边界

这是 beta 版本，适合备份后的试用，不宣称已达到长期稳定版质量。自动测试和本机打包自检不能替代所有设备与模型上的验证；本次未完成不同模型服务、Windows 10/11 全版本及全新实体机器的兼容矩阵。

- 关系图为基础能力；正文自动生成时间轴、多线时间轴和相对时间推算不在本次发布范围。
- 不提供自动更新、旧 Novalist 就地升级或 Electron 项目格式兼容保证。旧记忆、设定、关系图、缓存和回收站不导入。
- 更换程序时先退出并备份项目，再解压新包；勿覆盖项目目录。运行配置位于 `%APPDATA%\DeepSonder\PySide6`，缓存位于 `%LOCALAPPDATA%\DeepSonder\PySide6`。
- AI 任务会按需将正文与相关资料经 `dsh` 发往用户配置的服务；基础编辑使用本地文件。详见 [隐私说明](https://github.com/xiauho/DeepSonder/blob/pyside6-v0.1.0-beta/PRIVACY.md)。

问题反馈请附版本、复现步骤和脱敏后的错误信息，勿公开小说私稿、API 密钥或个人配置。安全问题遵循 [安全政策](https://github.com/xiauho/DeepSonder/blob/pyside6-v0.1.0-beta/SECURITY.md)。
