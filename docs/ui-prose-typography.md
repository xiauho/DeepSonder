# UI 细化第四步：正文字号与行距

上一阶段可调整行宽已提交为 `30d9a51`。本阶段将验证过的纯显示行距组件接入正式章节编辑器，并补齐设置预览、保存／放弃及已有偏好迁移。

## 使用方式

打开“设置 → 写作”，可调整正文字号（12–36px）和正文行距（1.0–2.4 倍，0.1 步进）。1.0 指字体的自然行进高度；行距按该高度的倍数计算。

修改时只更新独立的只读样例预览；点击“保存设置”成功后才应用到正文。切换页面会保留设置草稿，“放弃修改”恢复最新已保存配置。保存失败时，设置草稿及错误提示保留，当前正文显示继续使用原配置。

“恢复推荐排版”只将字号、行距改为 18px、1.8 倍的草稿，不重置其他设置；仍需保存设置后应用。底部“恢复默认设置”保持原有的全局默认值草稿流程。

开始新的设置草稿时，清除状态栏残留的上一次“设置已保存”确认，避免与页面的未保存提示矛盾；AI 进度和其他消息保留原有独立来源。

## 已有用户与新配置

| 配置来源 | 字号 | 行距 |
| --- | --- | --- |
| 尚无本系列配置文件 | 推荐 18px | 推荐 1.8 倍 |
| 本系列已有配置，缺少行距字段 | 保留原字号；缺失或无效时使用原默认 16px | 保持自然行距 1.0 倍 |
| 已有明确排版值 | 校验范围后保留 | 校验范围后保留 |

配置格式从 6 升级到 7。迁移依据原始字段是否存在，不能因为字号恰好为旧默认 16px 就推断用户同意改为 18px。缺失字段在迁移前与新配置默认值分开处理；迁移可重复执行，后续读取保持一致。

迁移仅处理 DeepSonder-PySide6 自身的配置，不读取其他系列或旧安装目录的配置，不修改项目格式或正文。无效、非有限数值使用对应默认值，越界的有效数值限制到支持范围。

## 编辑器与数据保护

正式组件位于 `ui/prose_edit.py`，仍继承 `QPlainTextEdit`。其 `QPlainTextDocumentLayout` 子类调整视觉行的位置和块高度，不改字符／段落格式，不替换文本，不关闭或清空撤销，也不重置文档修改标记。

行距仅接入章节正文与设置预览；准备字段和资料表单继续使用原控件。字号／主题更新沿用原有外观控制器，行宽三种模式保持原偏好。排版修改不写入 Markdown，不改变加载修订、未保存草稿、反向选区、撤销历史或 AI 候选来源。

输入法存在 preedit 时，行距变更延后至组合提交或取消后应用。载入另一份文本即使未收到最终输入法事件，也不会让待应用的显示偏好停留在旧状态。组合提交仍是正常文本编辑，可以按原规则撤销和触发来源过期保护。

历史原型脚本仅保留正式组件的导出别名，正式应用不依赖 `scripts/`；原型安全用例继续测试同一份实现，避免维护两套排版代码。

## 验证与限制

- 保留原型中的 14 项安全测试，验证实际行高、换行、点击定位、键盘导航、滚动锚点、末行、查找高亮、Unicode、输入法组合事件及正文历史。
- 新增排版设置专项测试，覆盖新旧配置、缺失字段、迁移幂等、异常数值、独立预览、推荐草稿、真实配置写盘、放弃、失败、主题切换、正文选区／撤销／修订以及真实本地待审结果保护。
- 布局矩阵使用独立临时项目和配置，组合浅／深色、1100／1440／1600px、普通／放大界面字号、16／18／24／36px 正文、自然／推荐／最大行距及三种行宽；检查实际设置保存、预览、正文排版、无横向溢出及把手与滚动条分离。

## 后续细化

字号、行距、恢复推荐和预览开关集中到顶部两行；预览可收起，收起不改变草稿或实际正文。保存与 AI 写作参考分组，避免混淆设置用途。1100px 窗口及放大界面字号下，排版控件无需滚动即可触达。

重复块高度查询复用已经应用的视觉行位置。缓存随文本块销毁，不保存到项目；文本修订、行数、倍数变化或 Qt 原生重排均触发重新计算。保留其他功能的块用户数据，存在其他数据时直接计算。字体、宽度、Unicode、输入法、撤销与回到自然行距继续经过同一排版路径。

整窗性能、最终回归与可执行包自检见[本地交付验收](ui-delivery-validation.md)。
