# 写作工作区优化：第一阶段

本阶段落实 2026-10-29 UI 方案中的正文阅读、工具栏可发现性和资料页密度优化，保留现有一级导航及 AI 审阅确认流程。

## 已实现

- 章节页默认采用居中的舒适行宽，按实际正文字体估算阅读宽度，在窄窗口自动使用全部可用空间。只改变现有控件布局，不修改文本、选区、修订基准及撤销历史。
- “视图 → 正文舒适行宽”及文档工具栏“更多”菜单可取消勾选，正文改为铺满可用区域。偏好保存在应用界面状态中，不写入项目内容或增加设置草稿。
- 正文移除整圈蓝色焦点边框，使用底部细焦点线；保留原字号偏好及光标、选区显示。其他 Markdown 编辑与预览的边界保持原样。
- 工具栏显示“参考”“专注”“更多”“AI 创作”。“更多”提供保存、行宽、目录显示、文档定位和页内查找；原菜单及快捷键继续生效。
- 工具栏在内容区变窄、字号增大、标题状态变化时重新测量并分行，不重建动作或输入控件。
- AI 菜单按“创作”“审校”“资料与文风”分组，所有原动作和不可用原因继续可达；生成、取消、待审和写入确认逻辑保持原流程。
- 标题区不重复显示正文字数，统计统一保留在页脚。准备栏摘要使用单行省略，鼠标提示保留各项有内容／空白状态，各项仍然可选。
- 资料页使用连续表面和分隔线，弱化模块外框与“结构固定”说明；保留输入边界、原文提示、同步只读区、更多菜单和恢复操作。“分区”按钮增加文字，手动“保存”改为次要操作。

## 使用方式

日常写作可直接使用默认行宽。需要更长的行时，打开文档右上方“更多”，取消勾选“正文舒适行宽”；再次勾选即可恢复，重启仍沿用上次选择。

“参考”打开原写作助手，仍包含本章资料、记忆和检查结果。保存使用“更多 → 保存”、文件菜单或 Ctrl+S；自动保存设置与冲突处理方式保持原样。

## 验证范围

新增 tests/test_reading_workspace.py 验证：

- 编辑后改变行宽、主题及窗口尺寸，保留同一正文控件、选区、未保存内容和撤销历史，不写入磁盘。
- 行宽偏好跨窗口恢复；偏好文件不包含正文。
- 更多菜单复用原保存和定位动作；实际保存写入目标章节。
- 1100px 窄窗口、放大字号下工具栏完整显示，保存失败提示持续可见。
- 进入／退出专注模式保留实际正文焦点、草稿和行宽偏好。
- 准备栏在结构化／自由格式章节间切换时更新提示，不残留上一章状态。

现有正文、资料、导航、AI 审阅、过期上下文和保存保护测试随完整回归运行。实际截图和测试结果记录在 output/ui-implementation-phase1-20261029/，预览只使用临时项目。

最终结果：134 个测试模块、1143 项测试，10 项按既有条件跳过，无失败；应用资源自检及补丁格式检查通过。150%／200% 缩放下，明暗主题、1100／1440px 窗口和普通／放大字号共 16 组布局检查通过。
