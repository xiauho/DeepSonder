# 模块化资料：第六阶段整体验收

验收日期：2026-10-17。范围仅为 DeepSonder-PySide6。

第五阶段已提交为 `8e9b0f3`。本阶段补充连续操作验收、修复验收发现的问题，并进行全量回归、界面与本地构建检查。

## 连续操作场景

[验收用例](../tests/test_canon_acceptance.py) 使用真实主窗口、临时项目和本地合成数据：

| 场景 | 验收内容 |
| --- | --- |
| 编辑与重开 | 导语、模板字段、自定义模块、字段与条目管理；折叠后全局保存、连续保存、快捷打开及关窗重开；导航缺项同步更新；未编辑尾部、BOM、CRLF和其他文档保留 |
| 外部修改冲突 | 本地草稿与磁盘版本分开保留；差异显示不误报整篇换行；草稿另存、取消重载、确认重载后继续编辑 |
| 角色同步 | 取消预览不写入，确认后只应用所选字段；同步区外字节不变，页面和导航更新；资料已修改时拒绝旧提案 |
| AI 待审结果 | 保存资料后使已有上下文快照过期；过期结果不解析、不发布；待审期间禁止删除资料；章节内容保持不变 |
| 窗口生命周期 | 导航、面板和阅读位置存在待执行回调时销毁窗口，再打开项目；没有回调访问已销毁控件 |

AI 验收使用本地合成结果及已验证记忆夹具，不发起真实模型请求。所有测试、草稿副本和截图均使用临时项目。

## 验收发现与修复

- 版本差异原先用自动归一化换行的读取方式处理磁盘文件，导致 CRLF 文件被误报为整篇修改。现与打开基准一样读取原始 UTF-8 文本。
- 延迟布局与按钮几何更新可能在窗口销毁后继续访问控件。布局恢复改用控制器拥有的单次定时器，并合并同轮请求；启动恢复、按钮与阅读位置回调绑定所属对象的生命周期。

## 复验方式

从仓库根目录执行：

```powershell
.venv/Scripts/python.exe -m unittest -v tests.test_canon_acceptance
.venv/Scripts/python.exe scripts/run_tests.py
.venv/Scripts/python.exe -m compileall -q main.py application core ui
.venv/Scripts/python.exe main.py --self-test
git diff --check
```

界面检查覆盖明暗主题、18px字体、520px内容区、150%及200%显示缩放，检查字段与条目管理、折叠、版本冲突和三个恢复按钮。全量测试结果与界面证据随本次验收记录保存。

## 2026-10-21：交互优化第一阶段

本次只调整分区内容状态和导航一致性，沿用现有文件格式、保存修订锁、冲突恢复和 AI 结果审阅机制。

- 大纲 ●/○ 表示“有内容／空白”，与左侧的模板缺项检查分别表达。关系选择器（包括清空和删除最后一行）、尚未落盘的预设字段及分组字段按当前草稿计算；导语、文本、原文备注和手写行同样读取实时输入。宽屏提示、窄屏列表提示和辅助阅读文本使用同一状态口径。
- 显式定位到页底分区时，即使无法将标题贴顶、或与前一个目标共享同一滚动值，也选中请求的目标。延迟布局完成后再次定位，确保折叠模块展开后标题可见；用户滚轮、键盘、滚动条操作后恢复按位置跟踪。切换资料和重建表单清除旧定位状态，延迟定位由控件拥有的定时器管理。
- 窄窗口打开分区列表不改变宽屏常驻大纲的显示偏好；分别验证原先显示与原先隐藏两种状态。
- 主窗口连续验收将重开后的折叠断言改为恢复原偏好，与既有跨会话持久化功能一致。

新增 [分区回归用例](../tests/test_canon_outline.py) 13项，覆盖实时状态、实际菜单动作、鼠标滚轮、键盘滚动、文档切换、字节不变及保存重载。显示检查使用临时资料，覆盖明暗主题、20px字号、520/1100px内容区和150%/200%缩放的8种组合：目标标题可见、无横向溢出，导航和折叠不标记内容修改、不写盘。源码编译、应用自检与补丁格式检查通过。

完整回归同时发现两处既有验收问题，并作测试层修正：上下文筛选候选数原先固定为9，未计入新项目默认世界观；已在原提交快照复现，现改为按夹具实际世界观文件数校验，保留相关性、容量及排序断言。工作区持久化测试原先只关闭窗口而不销毁，旧控件累积导致180秒模块超时；补齐逐例销毁及延迟删除后，原有15项场景在约25秒内通过，保持180秒限制不变。未修改上下文筛选、项目初始化或工作区持久化的业务逻辑。

最终全量复验：128个模块、1048项测试，10项需要原生窗口环境的测试跳过，零失败；持久化15项在约27秒内完成。编译、应用自检和补丁格式检查再次通过。本阶段使用临时项目，未改动仓库中的示例项目或个人项目；没有生成发布安装包。

## 2026-10-23：交互优化第二阶段

- 同步区以只读信息行显示截止章节、当前状态、位置、战力、持有物与关系；标准内容不再显示内部控制标记。截止章节按项目内现有文件解析名称，缺失或非法引用不提供跳转入口；点击时再次检查文件并复用既有文档路由，离页取消或保存失败时保留资料草稿。
- 同步区提供“同步角色档案…”入口，复用范围选择、提案预览及字段确认；任务运行或存在待审结果时禁用。原有同步连续验收改为点击该入口，验证取消预览不写同步内容、确认只更新所选字段、过期提案拒绝采用及标记外字节保持不变。
- 未知字段、重复字段、不完整标记、额外手写行和区块外内容不会被部分解析后丢弃：显示核对提示，提供完整只读原文查看。打开、复制或关闭展示均不改写文件。
- 页头保存状态单独占据固定位置，统一显示“已保存／待保存／保存失败／外部版本变化”；实际写盘成功短暂显示“保存成功”。新编辑、换文档、失败及冲突优先于成功反馈，超时不会隐藏错误；干净文件重复保存不制造写入通知。
- 折叠模块保留管理菜单；系统区块使用“结构固定”和“自动同步·只读”区分权限，核心结构保护保持不变。定位改用整行标题顶部，避免窄窗口下长标题换行后裁掉首行。

新增 [展示与反馈测试](../tests/test_canon_feedback.py) 15项，并补充2项真实主窗口章节导航验收；第一阶段同滚动值定位测试使用能同时容纳两个页底模块的视口，继续校验相同滚动值下的目标切换。界面离屏检查覆盖明暗主题、20px字号、520/1100px内容区、150%/200%缩放的8种组合：标题完整可见，无横向溢出，文件字节不变。

最终全量复验：129个模块、1065项测试，10项需原生窗口环境的集成测试跳过，零失败。只读信息标签与输入字段标签分别命名、复用同一视觉样式，原有长字段防截断检查保持不变。源码编译、应用自检及补丁格式检查通过；仅使用临时项目和合成资料，未改动示例或个人项目。

## 2026-10-24：交互优化第三阶段

- 文本与结构操作纳入当前资料的统一历史，覆盖导语、字段值、分组字段、正文、原文、手写行、区块间备注、关系行，以及模块／字段／分组的新增、改名、排序和删除。编辑菜单、Ctrl+Z／Ctrl+Y、输入框右键菜单使用同一顺序，不会在另一个字段或隐藏章节中执行撤销。
- 连续输入与同方向删除合并，停顿、光标移动、焦点切换、粘贴、输入法提交和结构操作划分步骤；取消、无变化操作及失败校验不新增历史。快照保留原始输入，因此未闭合代码围栏等临时无效草稿也能撤销，保存时仍需通过既有格式校验。
- 普通保存和自动保存保留历史；撤销与重做根据最近保存版本更新待保存状态，并继续走原有修订指纹检查。历史不恢复旧磁盘指纹、不主动写盘、不覆盖外部版本，也不隐藏保存失败或版本冲突。保存后沿旧历史恢复原稿并再次保存，可完整恢复 BOM、CRLF 与未编辑区块字节。
- 恢复被删除模块时保留稳定身份、内容和原位置，并展开、定位；输入焦点和选区随目标恢复。字段排序按字典的插入顺序比较，避免普通字典相等判断漏掉排序步骤；选区长度按 Qt 的 UTF-16 位置计算，保留包含表情的选区。关系行最后一行的删除、新增以及空行均能往返恢复。
- 历史仅在内存中，最多100步及16 MiB快照对象估算内存；超限释放较早步骤，当前超大草稿保持完整。切换资料、放弃修改、显式重载、干净资料接受外部版本或项目清空后清理，不写入偏好或项目文件。

新增 [文档历史测试](../tests/test_canon_history.py) 18项；真实主窗口增加“输入→新增字段→输入字段值→改名→排序→删除→自动保存→连续撤销／重做→全局保存”验收。同步区与未编辑尾部保持原字节，隐藏章节和另一份资料不受影响；原有同步预览、AI待审与冲突恢复验收继续执行。

界面检查使用临时项目，覆盖明暗主题、20px字号、520/1100px内容区与150%/200%缩放的8种组合：撤销删除后标题、正文和选区可见，无横向溢出，页头显示待保存，撤销本身不改写磁盘。源码编译、应用自检与补丁格式检查通过；未改动示例或个人项目。

最终全量复验：130个模块、1084项测试，10项需原生窗口环境的集成测试跳过，零失败。工作区持久化15项约23秒完成，保留原有180秒超时；本阶段未生成发布安装包。
