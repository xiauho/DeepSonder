# PySide6 UI 第四轮优化

日期：2026-09-17

## 目标与交付

在前三轮的布局简化、任务面板和状态恢复基础上，减少查找文档、发现命令以及返回正文时的操作次数。

| 入口 | 行为 |
| --- | --- |
| 左侧查找 / Ctrl+P | 跨章节与资料类别快速打开文档 |
| Ctrl+Shift+P / 帮助菜单 | 搜索现有菜单命令、查看快捷键和禁用原因 |
| F6 | 返回当前文档，保留源码或只读预览模式 |
| Ctrl+Alt+F | 展开目录并聚焦搜索，选中已有搜索词 |
| Ctrl+Alt+L | 定位当前文档，展开目录并清除过滤条件 |

## 交互细节

- 搜索复用当前导航目录中的标题、分类和相对路径，不读取正文，不访问其他项目或网络。支持不区分大小写的多关键词匹配；标题前缀匹配优先。
- 空查询按已有阅读记录优先列出最近文档，随后列出其他资料；记录沿用第三轮的本地偏好，不额外保存搜索词或正文。
- 结果显示文档分类和相对路径，命令显示快捷键。最多显示前 80 项，并显示总结果数及缩小搜索范围的提示。
- 可用方向键选择、双击或 Enter 打开、Esc 关闭。没有匹配项和没有项目分别提供下一步提示。对话框内 Ctrl+P / Ctrl+Shift+P 可以切换模式。
- 禁用命令可被选中以阅读原因，但不能执行；执行前再次检查状态，避免搜索打开后任务状态变化造成误操作。
- 主窗口持有菜单动作的快捷键，专注模式隐藏菜单后快捷键仍有效；Esc/F11 限定主窗口，避免干扰模态对话框。
- 文档入口复用现有文档服务与打开流程。保存失败不切换文档；已删除、越界或其他项目的旧结果无法打开。AI 任务和写入确认流程保持原有保护。

## 验证与边界

使用临时小说项目验证全文档类别检索、最近访问排序、5000 条目录元数据的显示上限、无匹配提示、键盘导航、实时禁用检查、保存失败、删除文件、项目切换、专注模式及实际快捷键事件。预览截图位于忽略目录 `build/ui-review-phase-4/`，包括窄窗口、浅色、深色和 150% 缩放。

这是文档标题与命令检索，不包含跨章节正文全文检索、模糊拼音检索或后台索引。本轮不修改 Electron、不调用真实 AI 服务，不使用示例小说作为测试写入目标。


验证结果：

- 全量 QApplication 回归：611 项通过，无跳过。
- 150% 缩放下的快速入口、紧凑布局和分类导航：23 项通过，无跳过。
- 编译检查、运行资源自检与 `git diff --check` 通过。
- 修复了测试发现的专注模式下菜单隐藏导致快捷键失效问题；实际 Ctrl+P、Ctrl+Shift+P、Esc 按键事件已覆盖。
