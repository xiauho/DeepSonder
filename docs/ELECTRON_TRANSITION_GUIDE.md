# Novalist Electron 迁移、备份与恢复指南

本文适用于从当前 PySide 版本迁移到 Electron-only 预发布版。Electron
版本只接收正文导入；旧项目中的角色卡、世界观、时间线、记忆和其他结构化资料
不会直接复制到新项目，而是由正文重新识别并经用户审核后建立。

## 安装前备份

1. 退出 Novalist，确认没有仍在写入项目的后台任务。
2. 完整复制旧项目目录到另一个位置，目录名建议包含日期和原版本号。
3. 再单独保存正文：旧项目通常位于 `outline/chapters/`，也可以导出为一个
   Markdown/TXT 文件或只包含正文文件的目录。
4. 随机打开备份中的至少两章，确认文件可读；不要只确认 ZIP“能够创建”。
5. 在 Electron 完成正文数量、顺序和内容抽查前，不要删除旧项目或旧程序。

备份中不得遗漏正文。结构化资料可保留用于人工核对，但不能作为 Electron 新项目
的权威导入来源。

## 首次迁移

1. 验证发布页给出的版本、签名和 SHA-256 后安装 Electron 版。
2. 选择“导入正文”，指向旧项目目录、正文目录或单个 Markdown/TXT 文件。
3. 在导入预览中核对章节数量、顺序、标题、空章节警告和来源摘要。
4. 创建新的 schema-v2 项目；不要覆盖旧项目目录。
5. 抽查开头、中部、结尾章节，并保留新的项目目录独立备份。
6. 启动正文识别，逐批审核人物、关系、世界观和事件候选。未经审核的识别结果
   不会成为新项目知识。

以下内容需要重新配置或重建：界面设置、最近项目、角色卡、世界观、时间线、
故事状态及旧版 AI 派生资料。旧版结构化文件不会静默迁移。

## 恢复与回退

- NSIS 卸载不会删除项目目录或应用数据，但卸载前仍应保留独立项目备份。
- 若安装版无法启动，解压同一版本的便携恢复 ZIP 到一个新目录，不要覆盖原安装
  目录；运行其中的 `Novalist.exe` 并打开原 schema-v2 项目。
- 若项目文件本身损坏，先复制损坏目录留作诊断，再把最近一次已验证备份恢复到
  新目录并从便携版打开。
- 若必须退回旧 PySide 版本，只用它打开旧版项目备份；不要让旧程序尝试打开或
  转换 schema-v2 项目。

当前 Electron 预发布阶段不启用无人值守自动更新。升级使用新的签名安装包，
同时保留对应版本的便携 ZIP，直到新版本完成一次真实项目保存和重新启动验证。

## 验收清单

- [ ] 旧项目完整备份和正文独立备份均可读取。
- [ ] Electron 导入预览的章节数量和顺序正确。
- [ ] 新项目与旧项目位于不同目录。
- [ ] 人物、关系、世界观和事件均来自重新识别和人工审核。
- [ ] 安装版可以保存并重新打开项目。
- [ ] 同版本便携恢复包可以只读打开项目且不产生隐式迁移。
- [ ] 发布清单签名、程序签名和文件摘要均已验证。
