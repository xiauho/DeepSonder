# AI 审阅工作区：第三阶段

本阶段将当前延期审阅中的正文与记忆确认控件嵌入工作区，复用原结果协调器和业务提交检查。阶段二已本地提交为 `7610b37`。

## 使用方式

AI 任务完成后仍保持“待审阅”，不会自动展开或写入。点击任务面板“审阅结果”，或使用“视图 → 审阅 AI 结果”及命令搜索进入审阅。

空间足够时，工作区与审阅侧栏并排；窄窗口或大字号时，审阅占用完整内容区。页头显示任务、目标章节、来源状态和写入范围。正文及资料不会被候选预先替换。

- “稍后审阅／返回正文”、Esc、F6：收起视图，保留候选、当前稿件选择、勾选、文风例外及阅读位置。再次审阅恢复同一份控件，仅在本次会话保留。
- 切换工作区、打开文档或查看参考时先收起审阅，以免挡住所选页面；返回后仍可继续原审阅。若来源或当前章节绑定已变化，采用会被阻止。
- 原确认按钮位于可滚动审阅内容之外；滚动长篇内容时，采用和放弃操作仍可达。放弃会结束本次审阅并释放结果；收起不会。
- 审阅期间继续阻止新 AI 任务、切换项目和退出。当前结果必须明确采用或放弃，不会因面板隐藏而静默丢失。

## 能力与保护矩阵

| 结果类型 | 保留的审阅能力 | 差异与写入边界 |
| --- | --- | --- |
| 按章纲生成正文 | 推荐稿／首次稿选择、篇幅与纠偏说明、重新补写、伏笔反馈和作者选择 | 比较原正文与所选候选；明确确认替换或写入空白正文，正文仍需保存。伏笔状态仍在章节保存成功后才生效 |
| 章节续写 | 当前结尾、目标与生成量、推荐稿／首次稿、重新补写 | 差异只比较结尾片段与待追加内容，明确说明范围；仅追加到目标章节正文末尾 |
| 一致性修复 | 原文、替换内容、原因与保留事实 | 比较唯一连续替换；原文失去唯一匹配时拒绝应用 |
| 选区扩写／文风润色／审校 | 默认不勾选、逐项采用、原文与理由、规则提示、例外互斥选择 | 差异按当前勾选生成；不勾选的原文保留，例外需明确确认，正文修改可撤销 |
| 故事记忆 | 摘要、状态 Patch、冲突／警告、下游记忆失效范围 | 明确确认后由原服务写入摘要与状态；不把提案伪装为文件逐行差异 |
| 被阻断的记忆 | 完整冲突证据、事实与正文锚点、定向重试、重提事实、可隔离部分审阅 | 点击“审阅可用部分”不写入；必须在第二份预览核对排除项、重建摘要后再明确确认，全局阻断不提供绕过 |
| 一致性检查报告 | 延迟发布、过期来源校验、检查报告页及其中的修复入口 | 继续在检查报告页呈现；报告内发起的修复使用上述修复审阅 |

正文差异使用只读逐行文本，比较内容过大时明确说明未生成，展示量到达上限时明确提示。候选、写入回调和业务判断始终使用完整原数据，差异文本不参与写入。

## 来源与生命周期

审阅使用原任务保留的来源快照。显示期间周期检查，恢复及采用前再次检查；收起后暂停周期检查，恢复时重新核对。来源不匹配后，本次审阅锁定为过期，采用与补写按钮禁用，候选仍可阅读和复制。需要放弃后重新生成，不因撤销编辑而自动解锁旧结果。

扩写／续写在篇幅明显偏离时仍保留原二次确认，二次确认返回后增加最终来源检查，避免确认期间的编辑或文件变化导致旧结果被写入。记忆提交、原文唯一匹配、部分采用排除和文风源文本检查继续由原服务与工作流执行。

呈现层保持原同步审阅决策栈及 token 快照，用非模态 Qt 事件循环承载嵌入控件，工作区仍可使用。收起不退出决策栈，因此选择无需复制或重建；确认／放弃后才继续原校验和释放。记忆阻断消息的正文与证据直接呈现，按钮转交原消息框动作，不复制部分采用业务逻辑。

## 验证

tests/test_ai_review_panel.py 覆盖真实控件中的候选、差异、收起恢复、Esc/F6、导航、文风选择与例外、记忆冲突及第二次确认、续写重试、修复唯一匹配和快照保留。另用真实本地工作线程及 AIContextSnapshot 验证作者编辑、外部资料变化后的禁写；测试不调用模型。

tests/test_ai_result_coordinator.py 增加篇幅二次确认期间来源变化的扩写／续写回归。现有延期审阅、AI 取消、关闭与项目切换、数据冲突及其他 UI 回归继续执行。

实际截图与布局记录位于本地 output/ui-implementation-phase3-20261030/，覆盖明暗主题、1100／1440／1600px、普通／放大字号及 150%／200% 缩放。预览只使用独立临时项目，自动截图始终放弃候选并断言原文件字节不变。

最终完整回归：136 个模块、1165 项测试，10 项按既有条件跳过，无失败。新增 13 项真实审阅控件回归及 2 项最终来源检查回归通过；128 组审阅布局检查通过，其中 4 组补充候选稿与伏笔复核。应用资源自检及补丁格式检查通过。

本阶段不生成发布包，不提供永久任务历史或跨会话候选保存。
