# 真实正文阅读位置恢复

此前的界面位置记忆只绑定内部完整文本控件，实际章节正文的光标、选区和滚动没有正确记录。本次保留原有通用文档记录，并为章节增加独立的 `prose` 视图状态。

- 记录真实正文的光标、选区方向及字符阅读锚点，仅包含数值，不保存正文。
- 切章和重启恢复实际正文；旧记录按正文起点将完整文本UTF-16偏移转换为正文偏移。
- 字号、行距和窗口／行宽变化时，用持续跟随文本的QTextCursor保持阅读锚点，避免多次重排逐步向前漂移。
- 恢复回调绑定当前文档及载入代次，同一路径重新载入也会使旧回调失效。
- 越界、损坏及变短文档的位置安全限制，不更改正文、未保存草稿、撤销历史、修订或保存错误。

新增9项真实正文测试覆盖重启、切章、反向选区、连续重排、旧偏移、异常位置、延迟回调及草稿安全；原有15项工作区测试和14项行距安全测试保持通过。仅使用独立临时项目。
