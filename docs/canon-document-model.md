# 模块化资料与 Markdown 映射

适用范围：DeepSonder-PySide6 的角色卡、世界观及体系资料。Markdown 文件仍是唯一事实源，没有额外数据库，也不要求其他系列同步实现。

## 模块身份

模块不再以显示标题作为唯一定位方式。新建模块，以及首次编辑、改名或移动的已有模块，会保存隐藏注释，例如：

```md
<!-- deepsonder:module:v1 {"id":"c0681ca484c84d5e8637635a350922e6e","role":"text","schema":"核心规则"} -->
## 通行规则
```

- `id` 是模块身份，改名及排序后保持不变；同名标题不再导致操作落到另一个模块。
- `role` 保存字段、分组、文本等类型，因此空的自定义字段或分组模块不会在重开后变成文本。
- `schema` 保存原有模板语义；改名后的关系模块仍使用关系选择器，关系图仍能读取其关系。自定义模块使用空字符串。
- 对没有注释的旧文档，仅在内存中生成身份；打开或无修改保存不迁移整份文件。

已编辑正文使用现有 `novalist:section:v1` 起止注释界定范围。该标记名是本项目已有文件格式的一部分，与旧产品导入无关。有效模块身份注释从 AI 资料上下文中移除；围栏内的示例注释保留。同步区的只读保护不依赖可编辑的模块类型声明。

## 内容保留与保守降级

读取不归一化换行。无修改保存保持 UTF-8 原文，包括 BOM、混合行尾和文末换行。编辑某个模块时，只重排该模块，并使用其原有换行；其他模块保持原文。仅编辑手写行时优先原位替换。

解析时屏蔽代码围栏、HTML 注释、前置 YAML 及已识别的原始 HTML 区块中的伪标题或标记。重复字段、重复分组、混合结构或未知元信息不会合并进字典：表单显示原文区块和说明，保留完整内容。重复身份在内存中隔离，直到用户编辑相应模块后才写入修复身份。

这是一套针对资料文档的保守映射规则，并非通用 Markdown AST 编辑器。无法可靠识别的内容使用原文入口。新输入中会吞掉后续边界的未闭合代码围栏、注释或 HTML 区块，以及位于正文的应用分区标记，会阻止保存；草稿继续保留。标记示例可放入闭合代码围栏。

## 导语与区块外备注

资料标题、BOM、前置 YAML 和应用注释保持保护；其间的作者文字由“资料导语”编辑。已闭合分区后、下一模块前的文字由“区块间备注”编辑。移动模块时备注留在文档原有间隙，删除模块也保留备注。未标记的旧模块，其标题到下一个标题之间的文字仍属于该模块正文。

导语、区块间备注及逐行手写输入不能新增一级或二级资料标题，也不能注入应用控制标记；通过“新建模块”添加模块。文本模块及原文正文可在闭合分区内部包含二级标题。

## 验证边界

回归覆盖类型与身份重开、改名后语义、重复标题/字段/身份、围栏与注释、BOM 与混合行尾、导语多片段连续保存、备注移动删除、AI 资料过滤，以及角色同步区外原文保留。界面检查使用临时项目，并覆盖窄内容区、明暗主题、大字体和显示缩放。

## 字段、条目和折叠操作

字段型模块和分组条目均提供“添加字段”。自定义字段通过“更多”菜单改名、上移、下移或确认删除；模板预设字段保留名称与位置，值可编辑。名称重复、含冒号的字段名、注释和换行等会被拒绝。分组条目通过“管理条目”完成改名、排序与确认删除；自定义模块允许不含字段的空条目，重开后仍保留类型。

结构操作在草稿副本中收集全部输入，校验渲染后才替换界面，不会立即写盘。取消删除或校验失败保留当前输入。字段或条目改名后恢复其输入焦点与选择；删除的输入不转移撤销到其他字段。

模块左侧箭头可用键盘展开/折叠；表单顶部提供全部展开/折叠。模块标题行整行可点击折叠，结构操作（重命名、上移、下移、删除）收在每行右侧的 ⋯ 菜单中，不再常驻四个按钮。折叠状态按文件记忆并随界面偏好跨会话保留：重启或重开项目后首次打开材料即恢复上次的折叠模块，只持久化当前仍存在的模块 id，改名产生的失效 id 自动清除；会话内切换材料保留会话状态，切换项目时清空。折叠仅改变视图，隐藏正文及其操作按钮，输入继续参与保存。撤销会先展开其目标模块。同步区也可折叠，内容继续只读。

## 页头、保存与写作引导

- 空分区显示按分区登记的写作引导占位；模板预设字段同样给出示例，未登记的分区回退到按角色的通用提示。
- 查看差异、另存草稿与重新载入只在版本冲突或保存失败时浮现，不常驻页面底部；正常状态下页头只需保存与新建模块两个入口。
- 资料页与章节编辑器共用同一项自动保存设置：开启时按保存间隔静默写盘，离开表单页或切换材料前先尝试写盘，仅在写盘失败时才回退到 保存/放弃修改/取消 三选一；关闭时保留原有确认流程。修订锁、外部修改保留草稿、AI 写入确认等数据保护不随本项调整变化。
- 页内“分区”大纲在宽窗口常驻表单右侧，逐条列出资料导语与全部分区，用 ●/○ 区分是否已填写，点击即展开并跳转到该分区，滚动时高亮当前分区；窄窗口下自动收起，页头的“分区”按钮改为弹出同一份列表，避免挤压表单。已填写状态读取当前输入控件，未保存的编辑也会在短暂延迟后反映。

## 导航资料状态

角色与世界观条目显示缺字段/分区、已有同步记录或待同步，以及需核对的原文结构。主身份和别名提示与身份记录联动。体系条目继续显示核心/常驻等加载策略，完整性信息放入提示。宽侧栏使用文字状态列；窄侧栏把状态列压缩为着色圆点，颜色沿用同一套强调/静默规则，名称列只承载名称与身份提示，点圆点或右键都能打开同一个「资料状态」浮层；完整说明始终可从提示读取。

状态来自已保存文件；保存、外部重载和项目数据刷新后更新。文件解析结果按修订缓存，身份变化单独更新；无法读取的单个文件显示错误提示，不阻断其余导航。区块外作者备注不计为同步记录。

点击状态列（宽侧栏）或右键资料行都打开同一个“资料状态”浮层：先列出该资料的完整状态明细，体系设定继续在其中提供核心/非核心的 AI 加载策略（常驻规则只显示说明），角色行额外提供“同步角色档案”，最后统一提供“移入回收站”。入口行为不再随资料分类变化；窄侧栏的状态列同样是入口，只是显示为着色圆点。
