# Novalist v2.0.3-beta

> 历史档案：保留当时的品牌、版本、路径与规划。本文不是当前操作指南；其中已删除的工具或旧升级步骤不适用于当前系列。当前说明见 [README](../../../README.md)，归档索引见 [历史文档](../README.md)。

## 本次版本

- 优化 AI 上下文快照，按任务缩小指纹范围并减少大文件读取开销。
- 增加项目数据增量刷新，降低保存和资料更新时的界面重绘成本。
- 优化编辑器查找、高亮和统计计算，改善长文档输入体验。
- 增加外部文件修改检测，避免保存时意外覆盖磁盘内容。
- 限制 AI 输出面板日志规模，增加复制、清空、任务类型和耗时反馈。
- 修复章节 ID 生成、创建、导入和回收站恢复时的冲突问题。
- 补充相关性能、任务反馈、上下文快照和章节生命周期测试。

## 预览版限制

- 本版本仍依赖用户自行安装和配置的 DSh / DeepSeek Harness。
- AI 生成正文、设定检查结果和故事记忆更新仍需人工审核。
- 本版本为公开 beta 预览版，不建议直接用于不可恢复的正式写作流程。
