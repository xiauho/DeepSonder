# Novalist v2.0.0-alpha

> 历史档案：保留当时的品牌、版本、路径与规划。本文不是当前操作指南；其中已删除的工具或旧升级步骤不适用于当前系列。当前说明见 [README](../../../README.md)，归档索引见 [历史文档](../README.md)。

## 本次版本

- 将原“AI 续写”入口调整为“AI 扩写”。
- 根据章节目标、核心冲突、章节钩子和剧情简写生成当前章节正文。
- 扩写任务不再发送当前章节完整正文，降低长篇后段上下文压力。
- 增加扩写专用输出协议、完成提示和整章替换预览。
- 保留旧版 `continue_target_chars` 配置的自动迁移能力。
- 增加 Windows 长提示词场景下绕过 `dsh.CMD` 包装层的处理和长度保护。
- 修复浅色主题下 AI 弹窗颜色不一致问题。
- 出场角色按当前章节正文中的出现次数排序。

## 预览版限制

- 当前版本的主 AI 写作入口是“AI 扩写”；当前章节续写和新章节生成仍在后续开发计划中。
- 发布前应使用本机已配置的 DSh 完成一次真实扩写验证。
- AI 生成正文仍需人工审核后再保存或发布。
