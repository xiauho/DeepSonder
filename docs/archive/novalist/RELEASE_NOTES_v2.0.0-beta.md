# Novalist v2.0.0-beta

> 历史档案：保留当时的品牌、版本、路径与规划。本文不是当前操作指南；其中已删除的工具或旧升级步骤不适用于当前系列。当前说明见 [README](../../../README.md)，归档索引见 [历史文档](../README.md)。

## 本次版本

- 在 alpha 版本基础上重构 AI 任务执行、结果校验、确认写入和上下文保护流程。
- AI 扩写、设定检查和故事记忆更新均采用后台任务执行，避免冻结写作界面。
- 增加 AI 任务取消、超时提示、结果过期保护和章节切换保护。
- 扩写结果先进入预览确认，不会未经确认直接覆盖正文。
- 扩写协议失败时自动进行一次完整纠偏重试，并保留首次原始返回供人工查看。
- DSh 使用隔离工作目录，降低 AI 误读或修改小说项目文件的风险。
- 保留 Windows 长提示词保护、完成提示、浅色主题弹窗修复和出场角色排序优化。
- 增加 AI 工作流、任务生命周期、结果校验、项目数据和界面控制器测试。

## 预览版限制

- 当前主 AI 写作入口仍是“AI 扩写”；当前章节续写和新章节生成仍在后续开发计划中。
- 使用 AI 功能前应在本机完成 DSh 配置，并进行一次真实扩写验证。
- AI 生成正文、设定检查结果和故事记忆更新仍需人工审核。
- 本版本为公开 beta 预览版，不建议直接用于不可恢复的正式写作流程。
