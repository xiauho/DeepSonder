# Novalist v2.0.6-beta

> 历史档案：保留当时的品牌、版本、路径与规划。本文不是当前操作指南；其中已删除的工具或旧升级步骤不适用于当前系列。当前说明见 [README](../../../README.md)，归档索引见 [历史文档](../README.md)。

## 本次版本

- 首次提供 Windows x64 便携版软件包。解压 `Novalist-v2.0.6-beta-windows-x64.zip` 后即可运行 `Novalist.exe`，目标电脑无需预装 Python。
- 新增“帮助 → 检查更新”，从 Novalist 官方 GitHub Release 读取版本和发布说明，并仅允许打开受限的官方发布页。
- 设置中新增稳定版与测试版更新通道；自动检查默认关闭，用户主动开启后最多每 24 小时检查一次。
- 优化无更新提示：没有可用 Release 时显示“未找到发布版本”；存在 Release 且版本不高于当前版本时才显示“已是最新版”。
- 将设置迁移到当前用户的应用数据目录，并为未来更新下载缓存预留独立目录；旧设置会安全复制并保留原文件。
- 增加 Windows 可复现打包基线、无界面程序自检、SHA-256 校验文件和机器可读发布清单。
- 软件包随附项目说明及 Python、Qt/PySide6、PyInstaller 和字体所需的第三方许可证文本；缺少许可证时构建会停止。
- GitHub Actions 会在 Windows 与 Python 3.12 环境中完成测试、构建、自检和产物上传。

## 下载与校验

1. 下载 `Novalist-v2.0.6-beta-windows-x64.zip`、`SHA256SUMS.txt` 和 `release-manifest.json`。
2. 使用 `SHA256SUMS.txt` 核对软件 ZIP 的 SHA-256。
3. 将软件 ZIP 完整解压到可写目录，然后运行 `Novalist.exe`。

用户配置、小说项目、虚拟环境和更新缓存不会写入发布包。

## 预览版限制

- 当前更新功能只检查版本并打开 GitHub 发布页，不会自动下载、替换或运行更新文件。
- 本版本是便携目录包，不提供安装器、开始菜单快捷方式或自动卸载流程。
- 程序尚未进行 Windows 代码签名，首次运行时 Windows 可能显示来源或安全提示；请仅从本仓库的官方 Release 下载并先核对 SHA-256。
- 本版本仍依赖用户自行安装和配置的 DSh / DeepSeek Harness；AI 输出和对项目内容的修改均需人工审核。
- 本版本为公开 beta 预览版，正式写作前仍建议保留独立备份。
