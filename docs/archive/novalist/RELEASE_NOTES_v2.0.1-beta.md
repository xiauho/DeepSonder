# Novalist v2.0.1-beta

> 历史档案：保留当时的品牌、版本、路径与规划。本文不是当前操作指南；其中已删除的工具或旧升级步骤不适用于当前系列。当前说明见 [README](../../../README.md)，归档索引见 [历史文档](../README.md)。

## 本次版本

- 修复干净环境中界面图标字体未随仓库加载，导致导航图标显示为残缺文本的问题。
- 将运行时字体资源固定放入 `assets/fonts/`，并在字体不可用时安全隐藏图标文字。
- 增强 AI 上下文预算与历史章节范围控制，降低长篇项目中的上下文失控风险。
- 改进 DSh 任务执行、取消、超时和结果生命周期处理。
- 加强 AI 结果解析、项目数据读写以及章节导航和视图刷新联动。
- 增加作者维护的伏笔笔记，以及章节项目级回收站和恢复流程。
- 优化编辑器、设置、主题、导出和项目生命周期相关工作流。
- 增加 AI 工作流、任务上下文、项目数据和界面回归测试。

## 预览版限制

- 本版本仍依赖用户自行安装和配置的 DSh / DeepSeek Harness。
- 发布前应在本机完成至少一次真实 AI 扩写测试。
- AI 生成正文、设定检查结果和故事记忆更新仍需人工审核。
- 本版本为公开 beta 预览版，不建议直接用于不可恢复的正式写作流程。
