# Novalist v2.1.0-beta

> 历史档案：保留当时的品牌、版本、路径与规划。本文不是当前操作指南；其中已删除的工具或旧升级步骤不适用于当前系列。当前说明见 [README](../../../README.md)，归档索引见 [历史文档](../README.md)。

## 本次版本

- 重构 AI 任务的底层传参与响应协议：长上下文优先通过经过能力探测的临时文件桥接，不能安全使用时回退到命令行兼容模式；每次调用均生成不含正文与提示词的脱敏上下文诊断。
- 将“AI 扩写字数”统一升级为项目级“目标章节字数”。扩写与续写采用同一统计口径：排除空白、包含标点；默认目标为 3000 字，理想范围为目标的 95%～105%，审阅范围为 90%～110%。
- 完善扩写/续写字数闭环：首次结果低于理想范围时先执行一次完整纠偏重写，仍不足时按剩余差额执行局部补写；最多自动纠偏两次，不自动截断超长正文。
- 差额补写的锚点由程序从当前结果中提取并校验，不再要求模型自行提供 20～80 字锚点，避免正文约 1800 字时因锚点不合规而无法应用补写。
- 纠偏后仍未达到理想范围时显示结果预览，并提供“重新补写”与“仍然采用”；明显超出审阅范围时采用前需要再次确认。
- 续写按“目标章节字数－当前整章字数”计算本次所需正文，避免把目标字数误当作追加字数；空正文、已经达到目标或剩余不足 300 字时不会误启动续写。
- 记忆更新改为章节前状态、事实账本、Patch 提案和人工采用的分层流程。同章重新生成时可安全替换，前序章节变化会使受影响的后续记忆失效，避免新旧状态相互覆盖。
- 记忆协议强化角色字段与位置变更的事实依据校验：不能由正文直接支持的推断会被标记为警告或阻断，并可在界面查看证据、重试或放弃。
- 一致性检查改用结构化问题协议、唯一正文锚点和可验证修复预览；只对能够安全定位和替换的正文问题开放自动修复。
- 新增角色档案同步：仅从连续、已采用且版本有效的故事记忆中提取角色状态变更；逐字段确认后写入角色卡受管区域，并在修改前自动备份。
- 改进编辑器统计、AI 结果预览与任务状态反馈，使软件显示字数、目标范围、首次生成、纠偏次数和最终结果保持同一口径。

## 从 v2.0.8-beta 升级

`v2.0.8-beta` 已包含独立更新器和逐文件受管清单，可在“帮助 → 检查更新”中安全下载本版本；完成校验后选择“立即重启并安装”。更新器只替换发布清单内的程序文件，保留用户配置、小说项目与其他非受管内容，并在新版启动自检失败时回滚。

> 已知问题：已发布的 `v2.0.8-beta` 更新器在 `%LOCALAPPDATA%` 缓存与便携安装目录位于不同盘符时，会因 Windows 不支持跨卷原子移动而导致替换及回滚失败。跨盘安装请勿使用“立即重启并安装”，应将完整 ZIP 手动解压到新目录。后续修复版会将暂存和备份放到安装盘，并强制首个修复版本手动安装。

也可以从 GitHub Release 下载以下三个文件并手动安装：

- `Novalist-v2.1.0-beta-windows-x64.zip`
- `SHA256SUMS.txt`
- `release-manifest.json`

从 `v2.0.7-beta` 或更早版本升级时仍需完整解压到新的可写目录，不能只覆盖单个 EXE。无论采用哪种方式，升级前都建议另行备份小说项目。

## 预览版限制

- 本版本修改了 AI 任务的底层传参、提示词协议与协议缓存版本。不同模型和 DSh 环境仍可能产生格式不合规或字数不稳定的输出，所有生成结果和状态变更都应人工审核后采用。
- 修改已生成记忆的前序章节后，受影响的后续记忆需要按顺序重新更新并采用，角色档案同步只接受连续且版本有效的记忆范围。
- 自动安装仅支持无需管理员权限且目录可写的 Windows x64 便携包；源码工作区、只读目录和缺少独立更新器的旧包使用手动安装。
- 发布清单尚未使用独立 Ed25519 密钥签名，程序也未进行 Windows Authenticode 代码签名；当前信任边界仍依赖 GitHub HTTPS、仓库 Release 权限、资源摘要和本机验证状态。
- 本版本仍依赖用户自行安装和配置的 DSh / DeepSeek Harness；首次公开使用前建议先在项目副本中完成扩写、续写、记忆更新、一致性检查和角色档案同步的完整实测。
