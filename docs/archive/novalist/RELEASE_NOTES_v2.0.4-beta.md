# Novalist v2.0.4-beta

> 历史档案：保留当时的品牌、版本、路径与规划。本文不是当前操作指南；其中已删除的工具或旧升级步骤不适用于当前系列。当前说明见 [README](../../../README.md)，归档索引见 [历史文档](../README.md)。

## 本次版本

- 增加 AI 扩写前的上下文选择，可选择本次重点关注的伏笔和非核心体系设定；核心规则与核心体系按项目配置自动纳入。
- 增加扩写后的伏笔复核反馈。AI 只提供“可能已回收”的正文依据和判断理由，作者可在结果预览中逐条选择是否标记为已回收。
- 伏笔状态修改在正文确认写入并成功保存后才生效，取消、章节变化或保存失败不会误改作者数据。
- 修复模型返回标记不完整或嵌套时的正文清理，避免 `<NOVEL_TEXT>`、`<NOVALIST_TASK_DONE>` 等协议标记写入正文。
- 增加角色卡创建引导和缺失角色卡提示，支持从故事记忆中创建不覆盖已有文件的草稿角色卡。
- 增加体系设定的核心、非核心加载策略及项目级兼容迁移，保留常驻核心规则的始终加载行为。
- 优化资料树的紧凑布局：面板较窄时暂时隐藏规则类型标记，让资料标题占满可用行宽；面板恢复宽度后自动显示标记，不改变条目选择、打开和状态设置逻辑。
- 增强扩写、伏笔、项目数据、角色卡和 AI 结果确认流程的回归测试。

## 预览版限制

- 本版本仍依赖用户自行安装和配置的 DSh / DeepSeek Harness。
- AI 伏笔反馈只是辅助建议，不会自动替作者修改伏笔状态；正文、伏笔状态、角色卡和故事记忆仍需人工审核。
- AI 生成正文、设定检查结果和故事记忆更新仍需人工审核。
- 本版本为公开 beta 预览版，不建议直接用于不可恢复的正式写作流程。
