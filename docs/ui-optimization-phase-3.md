# PySide6 UI 第三轮优化

## 交付范围

- 跨重启恢复窗口大小、位置、最大化状态、目录及检查器的开关和宽度。已断开的屏幕位置会回退到可见屏幕；小屏幕下限制窗口大小。
- 每个项目记住最后打开的文档，每个文档记住光标、选区及源码滚动位置。章节删除后选择首个可用章节；文件缩短后限制光标位置。仅允许重新打开当前项目导航目录内存在的文件。
- AI 创作菜单显示不可用原因及下一步入口：打开项目、选择章节、查看任务、使用扩写或调整创作设置。禁用项使用次要文字颜色。
- 保存状态区分未保存、正在保存、已保存、保存失败。错误以红色标记和独立换行提示栏持续显示，继续输入不会抹去错误；成功保存或重新加载后清除。
- 长文档标题省略显示并保留完整悬浮提示；无搜索结果时可直接清除搜索；目录增加定位当前文档按钮。
- 修正主窗口向 DocumentController 传递 parent 时占用了 document_service 参数的问题，恢复真实文档服务的打开及保存调用。

## 状态存储与边界

生产入口将偏好写入 PySide6 专属配置目录中的 `ui-state.json`。测试可注入临时文件；未注入时仅内存存储。保存采用临时文件和原子替换。最多保存 50 个项目、每项目 100 个文档位置，读取时忽略超过 1 MB 或无效 JSON 的偏好。

状态只包含路径、布局、光标和滚动位置，不包含正文、未保存文本或 AI 结果。专注模式临时隐藏的组件不覆盖常规布局偏好；AI 待审阅结果仍要求处理后才可切换项目或退出。偏好写入失败不会阻止正文保存。

窗口坐标恢复由启动入口调用。源码位置可恢复，Markdown 预览阅读位置不在本轮存储范围。窗口关闭会保存最终布局，编辑位置和侧栏操作使用 800 ms 防抖写入；这不是未保存正文的崩溃恢复功能。
